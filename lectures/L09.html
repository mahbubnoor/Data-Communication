Why multiplex?

  • A link's capacity is usually far more than one user needs
  • Multiplexing lets n signals share one link: one cable, one fibre, one radio band
  • A multiplexer (MUX) combines them; a demultiplexer (DEMUX) separates them at the far end
  • Inside the link, each signal travels on its own channel

Left dark box = MUX · orange = one link carrying n channels · right dark box = DEMUX

Without multiplexing: n separate links, most of them idle most of the time.

FDM

Frequency-division: each signal gets its own frequency band

· analog technique

Frequency-division multiplexing (FDM)

  • Each source modulates its own carrier (AM or FM, Lecture 8), at a different frequency
  • The modulated signals are added into one composite signal on the link
  • Channels are separated by guard bands
  • The demultiplexer uses filters to split the channels, then demodulates each

Grey strips = guard bands: unused gaps that stop neighbouring channels from interfering.

At the receiver, band-pass filters pick out each channel; each is then demodulated.

Worked example: placing channels in a band

  • Given: three voice channels, 4 kHz each; a link band from 20 to 32 kHz
  • Total needed: 3 × 4 = 12 kHz; the link offers exactly 12 kHz
  • Shift voice 1 to 20–24 kHz, voice 2 to 24–28 kHz, voice 3 to 28–32 kHz
  • Receiver: three band-pass filters, then shift each back down to 0–4 kHz

The analog hierarchy: FDM in stages

  • Telephone companies once multiplexed voice in levels, each built from the one below
  • Group: 12 voice channels × 4 kHz = 48 kHz
  • Each level adds guard bands, so bandwidth grows a little faster than the channel count
  • Replaced by digital TDM (T-lines, E-lines) and fibre

Wavelength-division multiplexing (WDM)

  • WDM is FDM for light: each signal uses a different wavelength (colour)
  • A prism or diffraction grating combines the beams into one fibre and separates them again
  • Each wavelength carries its own high-speed data stream
  • DWDM packs wavelengths very closely, giving terabits per second per fibre

DWDM (dense WDM): dozens to over a hundred wavelengths per fibre, each carrying 100 Gbps or more.

Time-division multiplexing (TDM)

  • TDM is digital: inputs share the link by taking turns in time
  • Each input gets a time slot; one round of slots is a frame
  • In synchronous TDM every input owns a fixed slot in every frame
  • The link must be n times faster than each input, so slots are n times shorter

Interleaving, and the problem of empty slots

  • The MUX visits the inputs in a fixed order, like a rotating switch: interleaving
  • The DEMUX rotates in step, so each slot goes to the right output with no address
  • If an input is idle, its slot is sent empty
  • Bursty traffic (web, chat) leaves many slots empty

When inputs have different rates

  • Synchronous TDM is easy when all inputs have the same rate
  • Multilevel: split a fast input into several slower streams
  • Multiple-slot: give a fast input more slots per frame
  • Pulse stuffing: pad slow inputs with dummy bits up to a common rate

The digital hierarchy: DS signals and T-lines

  • DS-0 = one digital voice channel: 8,000 samples/s × 8 bits = 64 kbps (Lecture 5's PCM)
  • T-1 carries 24 DS-0s in synchronous TDM
  • One frame per sample period (125 µs): 24 bytes + 1 framing bit
  • Higher levels multiplex lower ones, adding overhead each time

E-lines: the European (and Bangladeshi) standard

  • Europe and most of the world, including Bangladesh, use E-lines instead of T-lines

Statistical (asynchronous) TDM

  • Slots are given only to inputs that have data; no empty slots
  • Each slot must carry an address (and, for variable-length slots, a length)
  • The link can be slower than the sum of all inputs, because not all are busy at once
  • The idea behind packet switching (Lecture 10)

Spread spectrum: using more bandwidth on purpose

  • Multiplexing saves bandwidth; spread spectrum deliberately expands it
  • Each station's signal is spread over a band much wider than it needs: BSS ≫ B
  • Spreading follows a pseudo-random code, independent of the data
  • Hard to jam, hard to eavesdrop, and many users can share the band
MultiplexingSpread spectrum
Goalefficiencysecurity, anti-jamming
Bandwidth per signalas small as possibleBSS ≫ B

Spreading is controlled by a spreading code known only to sender and receiver; to everyone else it looks like noise.

Frequency-hopping spread spectrum (FHSS)

  • The carrier hops among M frequencies, staying Th seconds on each
  • A pseudo-random code generator chooses the next frequency
  • Only a receiver with the same code and starting point can follow the hops
  • Bandwidth used ≈ M × B; several stations can hop independently in the same band

Direct-sequence spread spectrum (DSSS)

  • Each data bit is replaced by n chips from a spreading code
  • Chip = bit XOR code: a 1 sends the code inverted, a 0 sends it as is
  • The chip rate is n times the bit rate, so the bandwidth grows about n times
  • The receiver multiplies by the same code to get the bits back; others see noise

Key takeaways

  • Multiplexing lets n channels share one link; FDM and WDM by frequency, TDM by time
  • FDM link bandwidth = n·B + (n − 1)·guard; WDM is FDM for light
  • Synchronous TDM: link = n × input rate; slot = unit time / n; add framing bits
  • T-1 = 24 × 64 kbps + 8 kbps framing = 1.544 Mbps; E-1 = 32 × 64 kbps = 2.048 Mbps
  • Statistical TDM uses addresses; FHSS and DSSS spread bandwidth for security
