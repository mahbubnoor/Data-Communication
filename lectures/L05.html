Why and how we digitise: PCM

  • Analog data must be digitised before it can travel as bits
  • Pulse code modulation (PCM): the standard method, used in phones, CDs and recording
  • Three steps: sample, quantise, encode
  • The device that does it is a codec (coder-decoder)

Then line coding (Lecture 6) turns the bits into a digital signal.

Step 1: sampling

  • Measure the signal's amplitude at equal intervals Ts
  • Ideal sampling uses instant impulses: a mathematical model
  • Natural sampling switches the signal on briefly
  • Flat-top (sample and hold) reads a value and holds it while it is converted

Ideal: instant impulses

Natural: pulse tops follow

Flat-top: sample and hold

Sampling interval Ts (seconds) and sampling rate fs = 1 / Ts (samples per second). Flat-top, using a sample-and-hold circuit, is what real converters use.

How fast must we sample? The Nyquist theorem

  • To rebuild a signal exactly, sample at at least twice its highest frequency
  • Intuition: each cycle needs at least two samples, one up and one down
  • Before sampling, a low-pass anti-aliasing filter removes frequencies above fs/2
  • Sampling at the Nyquist rate or above loses no information

fs ≥ 2 × fmax

fmax = the highest frequency in the signal. 2 × fmax is the Nyquist rate.

SignalHighest frequencySampling rate used
Telephone voiceabout 4 kHz (filtered)8,000 samples/s
CD audioabout 20 kHz (hearing limit)44,100 samples/s
Studio audioabout 20 kHz48,000 or 96,000 samples/s

Engineers sample a bit above 2 fmax because real filters are not perfectly sharp.

Sampling too slowly: aliasing

  • Below the Nyquist rate, the samples also fit a slower, false wave
  • The receiver rebuilds that wrong wave: an alias
  • Example: a 5 Hz wave sampled 6 times per second looks like 1 Hz
  • Everyday sign: wagon wheels or fan blades that seem to spin backwards on video

Step 2: quantisation

  • Divide the range Vmin to Vmax into L equal zones of height Δ
  • Each sample is replaced by the middle value of its zone
  • The difference is the quantisation error, never more than Δ/2
  • More levels → smaller Δ → smaller error, but more bits per sample

Signal vs quantised: 8 levels (dashed boundaries)

Δ = (Vmax − Vmin) / L

|error| ≤ Δ / 2

How good is it? Signal-to-quantisation-noise ratio

  • Quantisation error acts like noise added to the signal
  • SQNR compares signal power with quantisation-noise power
  • Each extra bit halves Δ, so it quarters the noise power: +6 dB
  • Use it to choose n for a required quality

SQNR(dB) = 6.02 n + 1.76

n = bits per sample; for a full-range sine-wave signal

Bits per sample nLevels LSQNRTypical use
3819.8 dBClassroom examples
825649.9 dBTelephone voice
1665,53698.1 dBCD audio
2416.7 million146 dBStudio recording

Rule of thumb: each extra bit adds about 6 dB. A telephone line needing SQNR ≥ 40 dB needs n ≥ (40 − 1.76)/6.02 = 6.35, so 7 bits.

Non-uniform quantisation: companding

  • Speech is mostly quiet; uniform levels waste resolution on rare loud peaks
  • Companding = compress before quantising, expand after decoding
  • Small amplitudes get finer steps; large amplitudes coarser steps
  • Telephone networks use 8-bit μ-law or A-law (ITU-T G.711)

μ-law curve (μ = 255) vs straight line: quiet sounds get more of the levels

Two standards

μ-law: North America and Japan

A-law: Europe and most other countries

Both: 8 bits per sample, about the same quality as 12-bit uniform quantisation for speech

Step 3: encoding, and the resulting bit rate

  • Each zone index is written as an n-bit binary code, with L = 2ⁿ
  • Codes for successive samples are sent one after another: the PCM bit stream
  • Bit rate = samples per second × bits per sample
  • Minimum bandwidth of the digital signal ≈ n × the analog bandwidth

n = log₂ L bits per sample

bit rate = fs × n

Bmin ≈ n × Banalog

Last line: for a low-pass signal sampled at the Nyquist rate (B = fmax)

Worked examples: PCM bit rate and bandwidth

  • Telephone: voice filtered to 4 kHz, 8 bits per sample
  • fs = 2 × 4 kHz = 8,000/s; bit rate = 8,000 × 8 = 64 kbps
  • Minimum bandwidth: 8 × 4 kHz = 32 kHz, eight times the analog voice
  • CD stereo: 44,100 × 16 × 2 = 1,411,200 bps

At the receiver: the PCM decoder

  • Read n bits at a time and convert each code back to its level value
  • Hold each value until the next sample: a staircase
  • A low-pass filter smooths the staircase into an analog signal
  • The result equals the original plus quantisation noise

A simpler alternative: delta modulation

  • PCM sends the value of each sample; DM sends only the change
  • One bit per sample: is the signal above or below the staircase?
  • Very simple hardware, but needs a much higher sampling rate than PCM
  • Adaptive DM enlarges δ on steep slopes and shrinks it on flat parts

Each sample sends 1 bit: 1 = step up by δ, 0 = step down

Sending the bits: parallel and serial transmission

  • Parallel: n bits at once over n wires; fast but costly and short-range
  • Serial: one bit at a time over one channel; used for almost all links
  • Asynchronous serial frames each byte with start and stop bits
  • Synchronous serial sends a continuous stream; isochronous guarantees a steady rate

Parallel: 8 bits at once, 8 wires

Serial: 1 bit at a time, 1 wire

Asynchronous byte: start bit (0) + 8 data bits + stop bit (1)

Serial modeTimingExample
Asynchronousstart/stop bits per byte; gaps allowedUART, old modems
Synchronouscontinuous stream; frames carry timingEthernet, SONET/SDH
Isochronousguaranteed fixed delivery ratereal-time audio and video

Worked example: the cost of asynchronous framing

  • Each 8-bit character gets 1 start bit and 1 stop bit
  • So 10 bits travel for every 8 useful bits: 80% efficiency
  • At 9,600 bps: 9,600 ÷ 10 = 960 characters per second
  • Synchronous transmission avoids per-byte overhead, so it suits high speeds

Key takeaways

  • PCM = sample, quantise, encode; a codec does it
  • Sample at fs ≥ 2 fmax, or aliasing creates false frequencies
  • Δ = (Vmax − Vmin)/L; error ≤ Δ/2; SQNR ≈ 6.02n + 1.76 dB
  • Bit rate = fs × n; voice = 64 kbps; companding improves quiet sounds
  • Delta modulation sends 1 bit per sample; serial links are async, sync or isochronous
