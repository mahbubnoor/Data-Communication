Changing the carrier: three basic schemes, plus QAM

  • A carrier is a sine wave at frequency fc, chosen to fit the channel's band
  • The bits change one property of it: amplitude (ASK), frequency (FSK) or phase (PSK)
  • QAM changes amplitude and phase together
  • Needed whenever the channel is band-pass: radio, Wi-Fi, mobile, cable, DSL

Bit rate, baud rate and signal levels

  • Each distinct signal element (a particular amplitude, frequency or phase) is one of L types
  • Each element carries r = log₂L bits
  • Bandwidth depends on the baud rate, so more levels mean more bits in the same bandwidth
  • Textbook note: Example 5.2 is printed as 8000/10,000; it should read 8000/1000 = 8

S = N × (1 / r), r = log₂ L

N = bit rate · S = baud rate (signal elements per second) · L = number of different signal elements

Amplitude shift keying (ASK)

  • The carrier's amplitude changes with the data; frequency and phase stay fixed
  • Binary ASK uses two amplitudes; with one of them zero, it is on-off keying (OOK)
  • Bandwidth B = (1 + d) S, centred on the carrier frequency
  • Simple, but very sensitive to noise and fading; used in optical fibre (light on/off) and RFID

Frequency shift keying (FSK)

  • The carrier's frequency changes with the data; amplitude and phase stay fixed
  • BFSK: two carrier frequencies, f₁ and f₀, 2Δf apart
  • MFSK: L frequencies carry log₂L bits per element
  • More robust to noise than ASK, but uses more bandwidth; early modems, Bluetooth (GFSK), pagers

Phase shift keying: BPSK

  • The carrier's phase changes with the data; amplitude and frequency stay fixed
  • BPSK: two phases, 0° and 180°
  • Implemented by multiplying a polar NRZ signal (±1) by the carrier
  • Noise changes amplitude more than phase, so PSK beats ASK; no second frequency, so it beats FSK on bandwidth

Quadrature PSK (QPSK)

  • QPSK sends 2 bits per signal element (a dibit) using four phases
  • Built from two BPSK signals: one on an in-phase carrier (I) and one on a quadrature carrier (Q, shifted 90°)
  • First bit → I (1 = +, 0 = −), second bit → Q: four combinations
  • Ex. 5.7: 12 Mbps, d = 0 → S = 6 Mbaud → B = 6 MHz

Reading a constellation diagram

  • The horizontal axis is the in-phase carrier (I); the vertical axis is the quadrature carrier (Q)
  • Each dot is one kind of signal element, labelled with the bits it carries
  • Length of the line to the dot = amplitude; its angle = phase

Quadrature amplitude modulation (QAM)

  • QAM = ASK + PSK: change both amplitude and phase
  • Two carriers (I and Q), each with several amplitude levels
  • PSK alone is limited by how finely the receiver can tell phases apart; QAM spreads points over the plane
  • Same bandwidth rule as ASK and PSK: B = (1 + d) S

More points, more bits, same bandwidth

  • Bit rate = baud rate × log₂L, and the bandwidth depends only on the baud rate
  • So moving from QPSK to 64-QAM triples the bit rate in the same channel
  • Wi-Fi and LTE switch modulation many times a second as the signal changes
  • The limit: Shannon (Lecture 3) and noise, next slide

Why dense constellations need a clean channel

  • Noise moves each received point away from where it was sent: a cloud around each point
  • The receiver picks the nearest point (decision regions)
  • More points → closer together → a smaller cloud is enough to cause errors
  • So 16-QAM needs a higher SNR than QPSK, and 256-QAM higher still

Key takeaways

  • Digital modulation puts bits on a carrier: N = S × log₂L, and bandwidth follows S
  • ASK changes amplitude, FSK frequency, PSK phase; B = (1 + d)S (FSK adds 2Δf)
  • A constellation point's distance is amplitude, its angle is phase
  • QAM combines amplitude and phase: 4-QAM (= QPSK) carries 2 bits, 8-QAM 3 bits, 16-QAM 4
  • Denser constellations carry more bits but need a higher SNR
