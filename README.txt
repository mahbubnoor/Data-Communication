DATA COMMUNICATION COURSE SITE (https://mahbubnoor.github.io/Data-Communication/)
Md Mahbub E Noor, Department of CSE, University of Barishal

OPEN IT
  Double-click index.html. Everything (slides, labs, videos, fonts) is inside
  this folder, so it works on lab PCs with no internet.

PUT IT ON THE WEB
  Upload the whole folder as it is to any static web host, for example:
    - a university web server (copy the folder into the public web directory)
    - GitHub Pages (push the folder's contents to a repository, enable Pages)
    - Netlify / Cloudflare Pages (drag the folder onto the upload page)
  No server code or database is needed. index.html is the home page.
  When served from a web address, the QR code on each lab slide automatically
  points to that server's copy of the lab, so students can scan it.

SPEAKER NOTES AND CHECKPOINT ANSWERS
  The notes folder holds the speaker notes, including checkpoint answers.
  Press N (or the Notes button) in a lecture to show them.
  For a public, student-facing site, DELETE the notes folder before uploading:
  the decks work the same, and the Notes button simply disappears.

INTERACTIVE SLIDES (website only): 49 in total, marked "Interactive" next to the
  slide title. Lectures 1-14 each have at least one. Each has demo steps in its
  speaker notes (press N).
  Arrow keys move a slider while it is selected; press Esc (or click the
  slide background) to go back to arrow-key slide changes. A presenter
  clicker (Page Down / Page Up) always changes slides.

LIGHT / DARK
  The course home page and the labs follow the computer's light/dark setting.
  The "Dark"/"Light" button (top right) overrides it; the choice is remembered
  in that browser and shared by all pages. The slides themselves stay light.

FOLDERS
  index.html   course home
  lectures/    L01.html ... L14.html  (the 14 slide decks)
  labs/        the 13 interactive labs
  videos/      the 14 explainer videos
  media/       slide images (QR codes, video posters)
  notes/       speaker notes (delete for a student-facing site)
  assets/      fonts, styles and scripts

KEYS IN A LECTURE
  Right arrow / Space  next slide        Left arrow   previous slide
  Home / End           first / last      number+Enter jump to slide
  [ / ]                previous / next lecture
  L                    open the lab      F            full screen
  N                    speaker notes     Esc          close panels

GITHUB PAGES
  Put the contents of this folder at the root of the repository (or in /docs),
  then Settings > Pages > Deploy from a branch. The empty .nojekyll file tells
  GitHub to serve the files as they are.
